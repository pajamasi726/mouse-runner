# mouse-runner

Slack 데스크톱이 **자리 비움**으로 바뀌지 않게 해 주는 macOS 명령줄 도구입니다.

맥에 입력이 없는 시간이 1~8분 사이의 **무작위 시점**에 닿으면, 커서를 움직이지 않는 마우스 이벤트를 한 번 보내 맥의 유휴 시간을 0으로 되돌립니다. Slack은 10분 동안 입력이 없어야 자리 비움으로 바꾸므로 초록불이 유지됩니다.

- 네트워크를 쓰지 않고, Slack 계정이나 토큰도 다루지 않습니다.
- 컴퓨터를 쓰는 동안에는 아무것도 하지 않습니다. 이미 입력이 있기 때문입니다.
- 이벤트 간격이 매번 달라서 일정한 패턴이 남지 않습니다.

## 설치

macOS 13(Ventura) 이상에서 돌아갑니다. 실행 파일 하나로 Apple Silicon과 Intel 맥을 모두 지원합니다.

저장소가 private이라 `gh`로 받는 것이 가장 쉽습니다.

```sh
gh release download v0.1.0 -R pajamasi726/mouse-runner -p '*.tar.gz'
tar xzf mouse-runner_v0.1.0_darwin_universal.tar.gz
./mouse-runner -version
```

브라우저로 받았다면 macOS가 실행을 막습니다. 압축을 푼 뒤 격리 표시를 지우세요.

```sh
xattr -d com.apple.quarantine mouse-runner
```

## 처음 확인: 셀프테스트

```sh
./mouse-runner -selftest
```

손을 떼고 3초 기다리면 `성공`이 나와야 합니다. 권한이 없다는 안내가 나오면 아래 [권한](#권한)을 보세요.

## 실행

```sh
./mouse-runner                                   # 항상, 1~8분 사이 무작위
./mouse-runner -hours 09:00-18:00 -days mon-fri  # 평일 근무 시간에만
./mouse-runner -min 2m -max 7m                   # 간격 범위 바꾸기
```

끌 때는 `Ctrl+C`를 누릅니다. 실행 중에는 이벤트를 보낼 때마다 로그가 찍힙니다.

```
mouse-runner v0.1.0 · 1m0s~8m0s 사이 무작위 · 일정: 항상 · Ctrl+C로 종료
14:02:11 동작 중
14:06:43 입력 신호 보냄 (유휴 4m32s) · 다음은 유휴 2m7s 때
```

이벤트가 먹히지 않으면(실행 중에 권한이 사라졌거나 화면이 잠긴 경우 등) `경고: 입력 신호가 먹히지 않습니다`가 한 번 찍힙니다. 다시 먹히기 시작하면 `입력 신호가 다시 먹힙니다`가 찍힙니다.

## 옵션

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `-min` | `1m` | 이벤트를 보낼 최소 무입력 시간 |
| `-max` | `8m` | 이벤트를 보낼 최대 무입력 시간. 10분 이상이면 경고를 냅니다 |
| `-hours` | 종일 | 동작할 시간대 `HH:MM-HH:MM`. `22:00-06:00`처럼 자정을 넘어도 됩니다 |
| `-days` | 매일 | 동작할 요일. `mon-fri`, `mon,wed,fri`, `fri-mon` 형식 |
| `-selftest` | | 권한과 이벤트가 먹히는지 한 번 확인하고 끝냅니다 |
| `-version` | | 버전을 출력합니다 |

## 권한

입력 이벤트를 보내려면 macOS **손쉬운 사용** 권한이 필요합니다. 터미널에서 실행하면 **그 터미널 앱**의 권한을 따릅니다.

권한이 없으면 실행할 때 안내가 나오고 프로그램이 끝납니다. `시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용`에서 쓰는 터미널 앱(Ghostty, 터미널, iTerm 등)을 켠 뒤 다시 실행하세요.

## 동작 원리

1. 매번 `-min`~`-max` 범위에서 목표 시간 T를 무작위로 뽑습니다.
2. 맥의 무입력 시간이 T에 닿으면, 현재 커서 위치에 마우스 이동 이벤트를 하나 보냅니다. 커서는 움직이지 않지만 macOS는 입력이 있었던 것으로 칩니다.
3. 다음 T를 새로 뽑습니다. 직접 마우스나 키보드를 쓰면 무입력 시간이 저절로 0이 되므로, 그때부터 다시 셉니다.

한 번에 최대 30초만 자고 다시 확인합니다. 그래서 잠자기에서 깨어나거나 근무 시간이 시작될 때도 곧바로 반응합니다.

## 주의

- **화면 보호기와 자동 잠금도 함께 걸리지 않습니다.** 무입력 시간을 계속 0으로 되돌리기 때문입니다. 자리를 뜰 때는 `⌃⌘Q`로 직접 잠그세요.
- 화면을 잠근 상태에서도 초록불이 유지되는지는 아직 확인하지 않았습니다. 잠근 뒤 로그에 `경고: 입력 신호가 먹히지 않습니다`가 찍히면, 잠금 중에는 이벤트가 먹히지 않는 것입니다.
- 노트북 덮개를 닫거나 맥이 잠자기에 들어가면 자리 비움이 됩니다.
- 10분 넘게 손을 뗀 채 확인할 때 **내 폰으로 Slack을 열면 안 됩니다.** 폰에서 여는 순간 폰 때문에 초록이 됩니다. 동료에게 봐 달라고 하세요.

## 다른 맥에서 직접 빌드해서 실행하기

릴리스 파일을 받는 대신 그 맥에서 직접 빌드해도 됩니다. 그 맥에서 만든 파일이라 macOS가 막지 않으므로, 서명이나 `xattr` 명령이 필요 없습니다.

저장소가 private이라, 그 맥에서 쓰는 GitHub 계정에 이 저장소 접근 권한이 있어야 합니다.

```sh
# 1. 준비 (처음 한 번만)
xcode-select --install    # Xcode 명령줄 도구. 이미 있으면 "already installed"라고 나옵니다
brew install go           # Homebrew가 없으면 https://go.dev/dl 에서 macOS용 설치 파일을 받으세요

# 2. 소스 받기
gh repo clone pajamasi726/mouse-runner    # gh가 없으면: git clone https://github.com/pajamasi726/mouse-runner.git
cd mouse-runner

# 3. 빌드 (./mouse-runner 파일이 생깁니다)
make build

# 4. 실행
./mouse-runner -selftest
./mouse-runner
```

- Go는 1.27 이상이 필요합니다. 설치된 Go가 더 낮은 버전이면, 빌드할 때 go가 필요한 버전을 알아서 내려받습니다.
- 새 버전으로 바꿀 때는 저장소 폴더에서 `git pull && make build`를 실행합니다.
- 처음 실행할 때 권한 안내가 나오면 위의 [권한](#권한)을 보세요.
