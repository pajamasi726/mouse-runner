# mouse-runner 설계 (짧은 설계, 2026-11-20 승인)

## 의도
Slack 데스크톱은 10분 동안 입력이 없으면 자리 비움(away)으로 바뀐다. 이것을 **계정 정보를 밖으로 넘기지 않고** 내 맥 안에서 막는다.
클라우드 서비스(slackgreen.com, slack.green)는 Slack 세션 토큰을 업체 서버에 넘겨야 하므로 쓰지 않는다.

## 목표
- macOS의 "마지막 입력 후 경과 시간(유휴 시간)"을 읽는다. 10분 안의 **무작위 시점**에 커서를 움직이지 않는 마우스 이벤트를 1번 보내서 유휴 시간을 0으로 되돌린다.
- 단일 실행 파일(Apple Silicon + Intel 유니버설)을 GitHub Release로 배포한다.
- 근무 시간에만 동작하는 옵션을 둔다.

## 비목표 (이번 버전)
- Windows, Linux
- 메뉴바 앱, 로그인 시 자동 시작(LaunchAgent), 코드 서명과 공증
- Teams 동작 보장

## 안티 목표 (이렇게 되면 실패)
- 사용자가 컴퓨터를 쓰는 동안 끼어든다(커서 이동, 클릭, 키 입력).
- 계정, 토큰, 네트워크를 다룬다. 이 도구는 네트워크를 전혀 쓰지 않는다.
- 일정한 주기로 이벤트를 보내 기계적인 패턴이 남는다. (사용자 요청: "딱 정해진 시간이 아니라 10분 안에서 랜덤하게")

## 제약
- 입력 이벤트를 보내려면 macOS "손쉬운 사용" 권한이 필요하다. 터미널에서 실행하면 터미널 앱의 권한을 따른다(Ghostty는 이미 허용됨).
- 브라우저로 받은 파일에는 격리 속성이 붙어 실행이 막힌다. 그래서 `gh release download`로 받는 방법을 안내한다.
- 저장소는 private이고, 처음에는 비어 있었다.

## 접근 방식
| 방식 | 장단점 | 결정 |
|---|---|---|
| Go + cgo로 CoreGraphics 직접 호출 | Python으로 검증한 API를 그대로 쓴다. macOS SDK가 필요하다(Xcode 있음). | **채택** |
| purego(cgo 없이 호출) | 교차 컴파일이 쉽다. 하지만 CGPoint를 값으로 넘기는 등 구조체 인자 처리가 불안정하다. 타깃이 macOS 하나뿐이라 이점이 작다. | 제외 |
| 외부 도구(cliclick 등) 호출 | 따로 설치해야 하는 의존성이 생긴다. | 제외 |

## 정해진 동작
- **무작위 목표 시간 T**: [min, max] 범위에서 균등하게 뽑는다. 기본값은 `-min 1m -max 8m`이다(10분보다 2분 여유).
  - 유휴 시간 ≥ T가 되면 이벤트를 1번 보내고 T를 새로 뽑는다.
  - 사용자가 실제로 입력하면 유휴 시간이 저절로 0이 되므로, 그 시점부터 다시 T까지 기다린다.
  - 그 결과 유휴 시간은 max를 넘지 않는다. 즉 항상 10분 미만이다.
- **대기 방식**: 고정 간격으로 확인하지 않는다. `min(T − 유휴 시간, 30초)`만큼 자고 다시 확인한다. 이벤트 시점이 확인 간격에 맞춰 반올림되지 않고, 잠자기에서 깨어났을 때나 근무 시간 경계에서도 30초 안에 반응한다.
- **근무 시간**: `-hours 09:00-18:00`, `-days mon-fri`(목록·범위 지원, 예: `mon,wed,fri`). 둘 다 지정하지 않으면 항상 동작한다. 자정을 넘는 시간대(`22:00-06:00`)도 허용하고, 요일은 현재 날짜를 기준으로 판단한다.
- **시작할 때 권한 확인**: `CGPreflightPostEventAccess`로 확인한다. 권한이 없으면 `CGRequestPostEventAccess`로 요청하고 설정 방법을 안내한 뒤 종료한다.
- **로그**: 이벤트를 보낼 때마다 시각, 그때의 유휴 시간, 다음 목표 시간을 출력한다. 근무 시간에 들어가거나 나올 때도 출력한다.
- **`-selftest`**: 입력이 없는 상태가 3초 이어질 때까지 기다렸다가(최대 30초) 이벤트를 1번 보내고, 전후 유휴 시간과 성공 여부를 출력한다. 종료 코드는 성공이면 0, 실패면 1이다.
- **`-version`**: 빌드할 때 `-ldflags -X`로 주입한다.
- **검증**: min이 0보다 크고 max 이하인지 확인한다. max가 10분 이상이면 경고만 출력한다(차단하지 않음).

## 구현하는 사람에게 남긴 것
- 파일 구조, 로그 문구, 테스트 방식. 단, 무작위 타이밍과 스케줄은 가짜 시계로 단위 테스트하고, 실제 입력 API는 `-selftest`로 확인한다.
